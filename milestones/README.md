# 実行タスク

`tasks.json`が順序、依存、条件ID、必須コマンドの唯一の正。M0からM6まで13タスク。
M0はCLI/中継/会話/承認の検証を行う小さなプロトタイプ。成立後にM1でElectron基盤を移植する。
各実装タスクは `npm run verify:<小文字タスクID>` を作り、条件を検証する。未存在は失敗でありskipしない。
Nodeのassert/Vitest/Playwright等で振る舞いを検証する。常時exit 0や実装文字列の存在チェックだけでは不足。
実機が必要な条件は `.harness/evidence/<task>/` に日時・実行環境・CLI版・結果・関連ログ/画像を記録し、検証コマンドが存在と内容を確認する。
記録だけの捏造や模擬結果の流用は禁止。IME等を自動操作できなければ具体的な利用者操作を依頼し、その工程で停止する。
実装者は条件を変更できない。仕様上の問題はblockedとして記録し、根拠と質問を返す。
全体の実機確認にはモデル使用量が発生する。通常の回帰は隔離データと模擬CLIで行う。
